# 麦门人生模拟器 · 长篇失控版 3.0

本文保留 V3 离线玩法与测试记录。2026-10-20 公开发布及可选 MCP 接入以根目录 README.md 和 MCP_INTEGRATION.md 为准。

非官方本地分支喜剧小游戏。三个普通人只是想吃顿饭，却被送进不同的职业和世界。当前包含 **9 条路线、每局 9 次剧情选择、6 种随机遭遇、45 个独立编写的结局**（36 个普通结局 + 每条路线 1 个隐藏结局）。

## 正式入口

- 任务分支：`codex/maimen-life-demo`，本地开发分支；公开发布目标为 `origin/main`。
- 网页入口：`dist/index.html`，无需安装依赖或构建。
- 推荐预览：在项目目录运行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory dist`，打开 `http://127.0.0.1:8765`。也可直接打开 HTML，但存档行为取决于浏览器对本地文件的支持。
- `dist/story.js`：原有 9 条路线、18 种第二章身份与原件、36 个普通结局。
- `dist/events.js`：随机遭遇与条件、9 条路线各自的试炼和身份危机、9 个隐藏结局。
- `dist/engine.js`：随机抽取、状态转换、条件判定、物品消耗、后果、存档重放与精确回溯。
- `dist/app.js`：界面、条件提示、存档入口、事故小票与结局档案。
- `dist/style.css`：复古界面、九章进度、窄屏阅读布局。
- `tests/engine.test.cjs`：路线可达性、状态与前置条件回归测试。

## 九回合规则

| 章节 | 发生什么 |
| --- | --- |
| 1 一念之差 | 根据开局选择进入一条路线 |
| 2 身份变更 | 选择后续分支，得到身份与原始物品 |
| 3 意外来客 | 第一次随机遭遇 |
| 4 资格试炼 | 用原件或胶带取得认证，也可以临时蒙混过关 |
| 5 节外生枝 | 第二次随机遭遇 |
| 6 整备时间 | 赎回原件、买胶带、挣人情券或休息，只能做一件 |
| 7 身份危机 | 之前的认证或人情券能解决危机，延期会留下后果 |
| 8 最后插曲 | 第三次随机遭遇 |
| 9 人生拐弯 | 选择普通结局；解决危机且仍持原件可选隐藏结局 |

之后进行一次模拟点餐，再展示三年后的职业、前面决定留下的后果与完整九步记录。点餐不改变已经选定的职业结局。理智与离谱值是体验数值，不决定结局。

| 开局 | 三条路线 |
| --- | --- |
| 论文赶工人 | 学术事故、薯条悬案、DDL 时空 |
| 下班逃跑家 | 会议夺权、分身打工、纸袋创业 |
| 周末漫游者 | 猫国外交、取餐号宇宙、鸽子职场 |

## 随机与因果

每次新开局抽取三种不重复的遭遇：宇宙临检、人生售后中心、打印机罢工、纸箱边检、未来快递、人生合理性回访。使用开局种子固定本局顺序，回溯和刷新不会重新抽签；不同局可能碰巧抽到相同顺序。

- 身份真正限制行动：管理者可批准打印机休假，猫国代表可申请外交豁免，调查员可反查回访工号等。
- 原始物品和消耗品分开处理。原件换通行证后会从背包消失；胶带、人情券、通行证使用后扣除。每种物品最多持有一份，已有胶带时不能重复花钱购买。
- 寄存原件后，资格试炼的原件选项会锁定。可以提前买胶带通过，或即兴过关后用人情券解决危机。整备回合可以赎回原件；第八章才寄存则已错过赎回机会，选项会明确提示。
- 隐藏结局要求解决身份危机且持有原件，不能只凭最后一次点击获得。普通结局始终留有出口。
- 每次买道具、赎回都必须保留至少 ¥12，保证最后能选最便宜的虚构套餐。小票分别统计实际支出与收入。
- 延期、寄存/赎回、拒收未来包裹、待解释记录等会在结局留下相应后续。

**回到上个岔路**重放同一种子下的此前选择，准确恢复现金、数值、身份、物品和标记。结局页回溯也会撤销刚才的点餐。已解锁结局保留。

## 存档与边界

所有故事、菜单、价格与数值均为虚构。未接麦当劳 MCP，无真实订单、支付、登录或外部 API 请求。静态文件没有远程字体或图片依赖。

- `maimen-session-v3`：仅保存最新一局的开局种子、角色、选择序列、套餐与反馈页状态。读取时通过引擎重新验证并重放，不直接信任存档中的身份或正文。损坏或不合法存档忽略。
- 刷新后在首页点“继续上次冒险”；完成后可查看上次人生。新开局覆盖最新进度；明确重选角色会清除此局进度。
- `maimen-endings-v2`：沿用原有结局档案键与 36 个结局 ID，旧收集记录继续有效，新版总数扩为 45。V1 记录保留在旧键，不混算。
- 存档是当前浏览器、当前来源本机保存；不是云同步。浏览器拒绝存储时仍能玩，界面提示无法跨刷新保存。复制失败时提供手动复制窗口。

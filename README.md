# 麦门人生模拟器 · 本地试玩

非官方浏览器小游戏。扮演论文赶工人、下班逃跑家或周末漫游者，完成四次剧情选择、选择模拟套餐，生成结局和今日快乐小票。

## 正式入口

- 项目目录：`/Users/zzx/Documents/ChatGPT/好玩的`
- 网页入口：`dist/index.html`，可直接用浏览器打开，无需构建或安装依赖。
- 推荐预览：在项目目录运行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory dist`，打开 `http://127.0.0.1:8765`。
- `dist/engine.js`：角色、剧情、套餐、不可变状态更新及结局规则。
- `dist/app.js`：界面、交互、分享与结局收集。
- `dist/style.css`：响应式界面，无远程资源或字体依赖。
- `tests/engine.test.cjs`：穷举三角色共 243 条剧情路径及可购买套餐结局。

## 玩法与边界

每次选择改变预算、精力、心情，并累积稳妥、社交或自由三类倾向。四段剧情结束后，按最高倾向生成结局；平局固定依次优先稳妥、社交、自由。数值限制在 0–100，套餐不能超出余额，不能重复扣款。

所有菜单、价格、剧情和数值均为演示内容，未接入麦当劳 MCP，无真实点餐、支付、账户登录或网络 API 调用。不要把游戏数值当作营养数据。结局收集仅存储在当前浏览器的 localStorage；浏览器禁止存储时仍能正常玩。刷新会结束当前局，保留已收集结局。复制故事失败时显示可手动复制的文本。

# 🍟 麦门人生模拟器

## 本地新试玩：这班，猫不上

**好消息：这辈子不用打卡。坏消息：今天的饭还没着落。**

养一只麦当劳门口的橘白猫。七天、十四次选择，认识店员和熟客、交猫朋友、找到落脚处，看看它最后能混成什么样。

- 小橘有八种表情／姿态，带呼吸、睡觉、甩毛、轻跳、摸猫回应、姿态渐变和场景过渡。右上角可关闭动画，初次进入尊重系统“减少动态效果”。这是二维分层动画，不是连续走路动画或 3D 模型。
- 纸箱、软垫、饭碗、领巾等家当会显示在场景中。饭碗能带来后续早餐；熟人、猫朋友与记住的路真正影响后面的选项。
- 每局两个不重复的随机事件，来自下雨、熟人没来、拍照三类。回退、刷新与同局重试保持同一组事件。
- 三条生活方向与一个隐藏结果。结局可生成带实际猫状态和生活环境的 PNG 小票，由玩家自行保存和分享。
- 自动存档、逐步回退；家当与熟人信息默认折叠。无需登录、付费或等待现实时间。

**目前仅本地保存，尚未推送或上线。** 下方公开链接仍是此前的九回合版。本地运行后：`/` 是猫咪七天版，`/harbor.html` 是五回合码头样例，`/classic.html` 是九回合版。三者使用独立存档。

[玩法与画面规则](docs/CAT_DESIGN.md)记录本轮确认后的具体范围。首版的现实能力仍是可选的本机官方活动日历查询，没有自动下单或现实聚餐规划。

## 怎么运行

在线版直接点击顶部“开玩”。本地版不需要构建：

```sh
git clone https://github.com/zhouzixuan2333/maimen-life-simulator.git
cd maimen-life-simulator
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:8765/ 。适合喜欢文字冒险、无厘头剧情、分支收集的玩家，也适合想研究无依赖游戏状态机和 Agent Skill 的开发者。

## MCP 现实支线（本机可选）

本项目包含官方活动日历的本地接入代码与 Agent Skill。连接后，在游戏上方展开“现实支线”，查看麦当劳当期活动，为这场离谱冒险安排一顿现实午饭。

```sh
python3 scripts/mcd_bridge.py
```

打开 http://127.0.0.1:8766/connect ，按页面引导在本机输入官方 Token。只查询活动日历，Token 不保存、不上传到公开网站。公开在线版保持无需 Token 的完整游戏。

**已完成官方 MCP 真实联调（2026-10-20）：活动日历查询成功。已提交[官方报名 #908](https://github.com/M-China/mcd-developer-innovation-challenge/issues/908)，当前等待官方确认；报名是否成功以该 Issue 的官方回复为准。** 详情见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。使用 Agent 客户端时，可安装 [maimen-life-simulator Skill](skills/maimen-life-simulator/SKILL.md)。

## 开发与测试

- `dist/index.html` / `cat-app.js` / `cat.css`：小橘七天版入口、界面与动画。
- `dist/cat-story.js` / `cat-engine.js`：十四次行动、关系条件、物品、湿毛状态、存档与结局。
- `dist/cat-scene.js` / `assets/cat-states.png`：八姿态透明猫图、分层场景与 PNG 小票。
- `dist/harbor.html` / `harbor.js` / `harbor.css`：保留五回合码头样例。
- `dist/harbor-engine.js`：时间、零钱、目标、随机路况与可重放存档。
- `dist/classic.html`：原版九回合入口。
- `dist/story.js`：主线与普通结局。
- `dist/events.js`：随机事件、资格试炼、隐藏结局。
- `dist/engine.js`：纯状态机、条件判定、物品消耗、存档重放。
- `dist/app.js` / `style.css`：界面与本机存档。
- `scripts/mcd_bridge.py`：仅在本机运行的官方活动日历桥接。
- [开发记录](docs/DEVELOPMENT.md)：九回合规则、验证与回退基准。

```sh
node tests/cat.test.cjs
node tests/harbor.test.cjs
node tests/engine.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

小橘测试模拟 1,200 局，覆盖 54 个行动分支、四种结果、三类事件，验证前置条件、状态与画面一致性、存档和回退；这不是所有组合的穷举。五回合测试遍历三种路况下的 375 条完整路径，验证目标、花费、锁定、前置选择、存档与回溯。原版游戏测试覆盖全部 45 个结局和 6 类遭遇，并检查消费、锁定选项、精确回溯与存档恢复。MCP 测试使用模拟响应验证协议和错误处理；真实账号联调另有[脱敏验证记录](docs/MCP_VERIFICATION.json)。

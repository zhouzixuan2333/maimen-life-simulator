# 麦门人生模拟器 · 失控版 2.0

非官方本地分支喜剧小游戏。三个普通人只是想吃顿饭，三个关键选择却把他们送进了完全不同的职业和世界。当前包含 **9 条路线、30 个剧情节点、36 个独立编写的人生结局**。

## 正式入口

- 项目目录：`/Users/zzx/Documents/ChatGPT/好玩的`
- 任务分支：`codex/maimen-life-demo`，无 remote，只保存本地。
- 网页入口：`dist/index.html`，直接用浏览器打开即可，无需安装依赖或构建。
- 推荐预览：在项目目录运行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory dist`，打开 `http://127.0.0.1:8765`。
- `dist/story.js`：9 条路线及各自后续岔路、道具、身份、三年后结局。
- `dist/engine.js`：角色开局、剧情图构建、状态转换、结局、精确回溯。
- `dist/app.js`：界面、事故小票、复制报告、结局档案。
- `dist/style.css`：原版复古界面及失控版新增样式。
- `tests/engine.test.cjs`：剧情图与状态回归测试。

## 真分支规则

每个角色有 3 个开局选项，各自进入不同的路线；路线中再选 1/2，进入不同的后续事件；第三次选择得到 2 个不同职业与未来之一。因此是 `3 个角色 × 3 条路线 × 2 个事件 × 2 个未来 = 36 个结局`。

| 开局 | 三条路线 |
| --- | --- |
| 论文赶工人 | 学术事故、薯条悬案、DDL 时空 |
| 下班逃跑家 | 会议夺权、分身打工、纸袋创业 |
| 周末漫游者 | 猫国外交、取餐号宇宙、鸽子职场 |

结局由明确的剧情跳转决定，不再累计性格分数后发称号。理智和离谱值是体验数值，不决定结局。第二次选择改变身份并留下专属道具，小票会记录每个转折。末尾点餐只改变余额、数值和午饭小尾声，不会覆盖玩家已经选定的未来。

**回到上个岔路**通过重放此前选择恢复准确状态，包括被限制在 0–100 内的数值、现金、身份和道具；不通过简单加减回滚。结局页回溯也会撤销刚才的模拟点餐。已解锁结局保留，方便比较另一种人生。

## 数据与边界

所有故事、菜单、价格与数值均为虚构。未接麦当劳 MCP，无真实订单、支付、登录或外部 API 请求。静态文件没有远程字体或图片依赖。

结局档案仅写入浏览器 `localStorage` 的 `maimen-endings-v2` 键；V1 的旧记录保留在原键，不与新版本混算。存储被禁用时仍可玩，只是不跨刷新保留档案。刷新会结束当前一局。复制失败时提供手动复制窗口。
